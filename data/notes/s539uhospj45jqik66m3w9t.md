
> Sonnet 5

## 1. 문제 상황

싱글 레그 데드리프트 시 무릎 부담이 크게 느껴짐 → 균형을 잡느라 무릎이 흔들리거나 힌지가 아닌 스쿼트처럼 무릎을 굽히는 것이 원인일 가능성.

## 2. 무릎 부담 적은 대안 하체 운동

- **힙 힌지 계열**: 커틀스탠드 RDL, B-스탠스 힙 쓰러스트
- **순수 고관절 운동**: 스탠딩 힙 어브덕션/익스텐션, 편측 글루트 브릿지
- **무릎 사용하되 부담 적은 운동**: 스플릿 스쿼트(뒷발 고정, 넓은 스탠스), 낮은 박스 스텝업

### RDL Romanian Deadlift

- 무릎을 거의 안 굽히고 고관절 힌지 위주
- 서 있는 자세에서 시작 (바닥에서 시작 X)
- 햄스트링·둔근 자극에 특화
- "싱글 레그 데드리프트"는 사실상 "싱글 레그 RDL"을 지칭하는 경우가 대부분

## 3. 스플릿 스쿼트 vs 런지

| 구분        | 스플릿 스쿼트          | 런지                        |
| ----------- | ---------------------- | --------------------------- |
| 시작 자세   | 처음부터 앞뒤 스탠스   | 두 발 나란히 서서 시작      |
| 이동 여부   | 제자리에서 상하 이동만 | 내딛기(이동)가 포함됨       |
| 밸런스 요구 | 상대적으로 적음        | 모멘텀 컨트롤 필요, 더 많음 |
| 무릎 부담   | 전단력 적음, 안전한 편 | 착지 충격·무릎 전방 이동 큼 |

→ 무릎이 걱정된다면 **스플릿 스쿼트**부터 시작 권장.

## 4. 싱글 레그 데드리프트 복귀를 위한 밸런스 단계별 훈련

1. **정적 밸런스**: 한 발 서기(30초~1분), 반대 무릎 들어올리기
2. **힌지+밸런스 결합**: 벽 잡고 싱글 레그 힌지 → 케이블/밴드 지지 싱글 레그 RDL → 커틀스탠드 RDL
3. **동적 밸런스**: 스탠딩 버드독, 싱글 레그 박스 터치

**추천 진행 순서**: 한 발 서기 → 벽 잡고 힌지 → 지지 있는 RDL → 무지지 싱글 레그 데드리프트 (각 단계 2~4주)
