# 포트폴리오 설계 정리

> 작성 기준일: 2026년 9월 9일
> 전제: 직장 재직 중(근로소득 있음), 현금흐름 불필요, 투자기간 10년 이상 / 30년 지향, 채권 제외

## 1. 자산 배분

### 기준안

| 자산       | 비중 | 역할                     |
| ---------- | ---- | ------------------------ |
| 성장주 ETF | 55%  | 수익 엔진                |

### 성향별 조정

|        | 성장주 | SCHD | GDX | 현금  |
| ------ | ------ | ---- | --- | ----- |
| 공격적 | 60~65% | 20%  | 10% | 5~10% |
| 기준안 | 55%    | 25%  | 10% | 10%   |
| 보수적 | 45%    | 30%  | 10% | 15%   |

### 비중 근거

- **성장주 55%** — 30년 지평 + 근로소득으로 하락장 추가매수 여력 있음. 주식 비중을 낮출 이유가 적음
- **SCHD 25%** — 세금 문제로 이 이상 확대는 신중히 (§4 참조)
- **GDX 10%** — 최대 낙폭 −80.3% 자산. 이 이상이면 하락장에서 리밸런싱 규칙 준수가 어려움. 5%는 존재감 없음
- **현금 10%** — **비상금과 분리할 것.** 6개월치 생활비는 포트폴리오 밖에 별도 보관. 섞으면 급전 필요 시 저점 매도하게 됨

## 3. 분산 효과 — 실제 크기

### 상관계수 (측정 기간에 따라 크게 변동)

| 조합            | 상관계수                     |
| --------------- | ---------------------------- |
| SCHD ↔ QQQ      | 0.6 내외 (최근 1년 0.1 미만) |
| SCHD ↔ VOO      | 0.8 내외                     |
| GDX ↔ S&P 500   | R² 0.07 (상관 약 0.26)       |
| VXUS ↔ 미국주식 | 0.8 내외                     |

### 정리

- **미국 대형주 ETF끼리 조합하는 분산 효과는 제한적.** 포트폴리오 분석 도구들이 SCHD+VOO+QQQ 조합에 대해 "분산 비율 하위 수준" 평가를 내림
- **GDX가 실질적 저상관 자산.** 베타 0.58, R² 0.07, 알파 7.86%(2006년 이후). 단 저베타 ≠ 방어적. R²가 낮아 베타 수치 자체가 의미 없음
- **하락 캡처(56.3%) > 상승 캡처(48.8%)** — GDX는 오를 때보다 빠질 때 더 붙음

### GDX 성격 — 금 대체재 아님

|           | GDX    | GLD    |
| --------- | ------ | ------ |
| 최대 낙폭 | −80.3% | −45.6% |
| 변동성    | 16~18% | 15%    |

금값 외 변수: 채굴비용(디젤·인건비), 통화(AUD/ZAR/CAD), 광산 소재국 정치 리스크, 증자 희석. 금 대비 1.5~2배 레버리지가 붙지만 배율은 고정 아님. 2011~2015년처럼 금값 횡보 중 광산주만 하락한 구간 존재.

지수 변경(2025년 9월 22일)으로 은 채굴·로열티·스트리밍까지 포함. 휘튼 프레셔스 메탈스가 4위 보유 종목. 구리는 배릭·뉴몬트·쯔진 등을 통해 부산물로 노출되나 의도된 배분 아님. 보수 0.51%.

## 4. 메가캡 고평가 문제

### 이것이 핵심 리스크

2000~2009년 S&P 500은 연평균 −0.95%로 1930년대 이후 유일한 마이너스 10년. 그러나 같은 기간:

| 자산               | 결과 (2000-2009) |
| ------------------ | ---------------- |
| S&P 500 (시총가중) | −0.95%/년        |
| S&P 500 (동일가중) | +5.1%/년         |
| 미국 소형가치주    | $1 → $2.21       |
| 신흥국             | 큰 폭 플러스     |

**"미국 대 비미국"이 아니라 "미국 메가캡 대 나머지 전부"의 문제였음.** 지역을 바꾸지 않고 가중 방식만 바꿔도 상당 부분 방어됨.

### 현재 밸류에이션

| ETF                    | PER    |
| ---------------------- | ------ |
| VUG                    | 33.5배 |
| VGT                    | 32.8배 |
| VUG 상위 10종목 집중도 | 65.5%  |

### 판단해야 할 단일 질문

**지금 미국 메가캡이 2000년처럼 비싼가.**

- "그때만큼은 아니다" → 미국 편중 유지가 일관된 선택
- "비슷하게 위험하다" → 분산 필요. 단 처방은 지역이 아니라 스타일

### 대응 옵션 우선순위

1. **소형가치 추가** (AVUV, VBR) — 2000년대 데이터상 가장 효과적이었던 조각. 배당이 적어 세금 부담도 낮음
2. **SCHD 비중 확대** (35~40%) — 방향은 맞으나 대형주라 소형 조각이 빠짐. 세금 불리
3. **성장주 일부를 VOO로 전환** — 집중도 완화
4. **VXUS 추가** — 우선순위 낮음 (§5 참조)

**현재 기준안의 한계:** SCHD 25%면 주식 부분의 2/3 이상이 여전히 고평가 메가캡. "걱정은 하지만 대응은 25%만" 하는 상태.

### 주의

소형가치와 미국 외 주식 모두 지난 15년간 부진. 2000년대에 통했다는 것이 다음에도 통한다는 보장 없음. 어느 쪽이든 "지금 비싼 것이 조정받는다"는 가정에 대한 베팅.

## 6. 운용 규칙

### 리밸런싱

- **연 1회** 정기 조정. 분기 리밸런싱은 거래비용·세금만 늘고 성과 개선 미미
- **±5%p 밴드 규칙** 병행 — 목표 대비 5%p 이탈 시 시기 무관하게 조정
- 하락 전에 규칙을 문서화할 것. 하락장 한복판에서는 대부분 규칙을 바꾸게 됨

#### 전체 조정

하나라도 밴드를 벗어나면 모든 자산을 목표 비중으로 되돌립니다. 규칙이 단순하고 판단이 개입할 여지가 없다는 게 장점입니다. 다만 GDX 하나 때문에 성장주와 SCHD까지 건드리게 되어 불필요한 매매와 세금이 발생합니다.

#### 부분 조정

벗어난 자산만 목표로 되돌리고, 그 차액은 현금 슬리브에서 주고받습니다. 거래 건수가 줄고 세금도 덜 발생합니다.

현재 구성에 현금 10%가 있으니 부분 조정이 잘 맞습니다. 예를 들어 GDX가 10%에서 15%로 불어나면 5%p어치를 팔아 현금으로 보내고, 반대로 5%로 줄면 현금에서 채웁니다. 다른 자산은 손대지 않습니다.

#### 절대값 밴드의 문제

5%p를 모든 자산에 똑같이 적용하면 형평이 안 맞습니다. 성장주 55%에서 5%p는 9% 변동이지만, GDX 10%에서 5%p는 50% 변동입니다. 즉 GDX는 사실상 거의 발동되지 않고, 성장주는 자주 발동됩니다.

**상대 밴드로 바꾸는 게 낫습니다**

목표 비중의 ±25%를 밴드로 잡는 방식입니다.

| 자산   | 목표 | 밴드      |
| ------ | ---- | --------- |
| 성장주 | 55%  | 41~69%    |
| SCHD   | 25%  | 19~31%    |
| GDX    | 10%  | 7.5~12.5% |
| 현금   | 10%  | 7.5~12.5% |

이러면 모든 자산이 비슷한 빈도로 발동됩니다. GDX처럼 변동성 큰 자산도 제 역할을 하게 됩니다.

#### 권하는 규칙

1. 연 1회 정기 점검 시 전체를 목표로 재조정
2. 그 사이에 어떤 자산이든 상대 밴드를 벗어나면, **해당 자산만** 현금과 주고받아 목표로 복귀
3. 현금 자체가 밴드를 벗어나면 그때는 전체 조정

#### 현실적인 조언 하나

밴드 규칙의 진짜 목적은 수익률 개선이 아니라 하락장에서 손이 멈추는 걸 막는 겁니다. 발동 조건과 매매 방향을 지금 종이에 적어두시고, 나중에 그 순간이 오면 계산만 하고 실행하는 구조로 만들어두세요.

특히 GDX는 최대 낙폭 −80% 자산이라 밴드 하단을 여러 번 칠 수 있습니다. 그때마다 추가 매수하는 게 규칙인데, 실제로는 "이건 뭔가 구조적으로 잘못된 것 같다"는 생각이 들기 마련입니다. 그 상황을 미리 예상해 두는 것과 아닌 것의 차이가 큽니다.

### 세금 (한국 거주자)

- SCHD 배당: 미국 원천징수 15% → 국내 금융소득 연 2,000만원 초과 시 종합과세
- **현금흐름이 불필요한데 배당에 매년 과세되는 구조** — 성장주 ETF는 매도 전까지 과세 이연
- 매도 시 해외주식 양도소득세, 연 250만원 공제
- 연금저축·IRP 활용 가능 여부에 따라 계산이 완전히 달라짐 → 별도 확인 필요

### 통화

원화 현금은 단순 현금이 아님. 위기 시 달러 강세로 미국 자산의 원화 환산 손실이 완화되는 헤지 기능 (2008, 2020 사례). 달러 현금으로 보유 시 이 완충이 없음. 현금 슬리브의 통화 결정이 생각보다 중요.
